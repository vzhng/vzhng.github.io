## Local development

Open this folder in Cursor (or any editor), edit files, then:

```bash
git add .
git commit -m "Your message"
git push
```

GitHub Pages publishes from the `main` branch root.

## Syncing across laptops

```bash
git pull   # before you start
git push   # when you finish
```
